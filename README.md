# ChronoVault

## Intelligent Cloud-Based Life Event & Memory Management System

**Tagline:** Never Forget What Matters.

ChronoVault is a cloud-based personal life event management platform that allows users to store, organize, and manage important life events such as birthdays, anniversaries, bill payments, subscription renewals, appointments, and document expirations.

The system uses AWS cloud services to provide secure authentication, cloud storage, serverless processing, automated reminders, and notifications.

## Objectives

- Centralize important life events
- Allow users to create, update, and delete events
- Support one-time and recurring events
- Provide automated reminders
- Send notifications to users
- Securely store user data
- Provide an organized dashboard
- Deploy the application on AWS

## AWS Services

- Amazon Cognito
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon EventBridge
- Amazon SNS
- Amazon S3
- Amazon CloudWatch
- AWS Amplify
